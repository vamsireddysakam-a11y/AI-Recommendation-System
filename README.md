# AI Recommendation System 🎬

## About the Project

This is a simple Python project that recommends movies based on the genres selected by the user. The main idea of this project is to understand how a basic recommendation system works using Python logic.

The program asks the user to enter one or more favorite movie genres, checks the available data, and then displays movies that match those genres.

This project was created as part of an Artificial Intelligence learning project to understand the basics of recommendation systems.

## Features

* Easy to use.
* Takes user input for movie genres.
* Supports multiple genres at the same time.
* Recommends movies based on the selected categories.
* Written using basic Python concepts.

## Technologies Used

* Python 3

## How It Works

1. The program displays the available movie genres.
2. The user enters their favorite genre(s).
3. The program searches for matching movies.
4. The recommended movies are displayed on the screen.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the Python file using:

```bash
python recommendation.py
```
